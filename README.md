# CSV → JSON

Утилита для конвертации CSV-файлов в JSON. C# / WinForms (.NET 8).

## Скачать
Готовый `.exe` — в разделе [Releases](../../releases).
Установка не требуется, .NET уже внутри.

**Требования:** Windows 10/11 x64.

## Запуск из исходников
Открой `CsvToJson.slnx` в Visual Studio 2022 и нажми **F5**.

## Возможности
- Выбор CSV-файла через диалог
- Опция «первая строка — заголовки»
- Предпросмотр JSON в окне
- Сохранение результата в файл
- Автоопределение кодировки (UTF-8 / cp1251)
- Корректная обработка запятых и кавычек внутри полей
